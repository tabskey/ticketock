## 风险与缓解 / Risks
- Fail-fast JWT secret (#1) breaks any environment without .env, including the README quickstart and the test suite — conftest and docs must be updated in the same change or boot/tests fail.
- Removing the refresh flow (D1=A) touches frontend AuthContext, client, schemas, services, and several tests; leaving any reference causes compile/test failures. Keeping it (D1=B) requires real rotation + revocation to actually close the security concern the review raised.
- Concurrency guard (#4): the SELECT ... FOR UPDATE approach is hard to assert deterministically in tests; the conditional-UPDATE + rowcount variant is more testable. Choose deliberately and write a test that exercises the conflict path.
- Index migration (#5) must add a working downgrade and correct down_revision (0005) or alembic upgrade/downgrade round-trip breaks.
- Reactive 401 handling (#8) risks an infinite retry loop or a refresh/redirect race; the retry must be bounded to a single attempt per request and must not fire for the refresh call itself.
- Dependency pinning (#9) can pin a version incompatible with the current code; verify install + full test run after pinning.
- Coverage gate (80%) is enforced: new code paths (revocation, 401 retry, indexes) must ship with tests or the gate fails.
